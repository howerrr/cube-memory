# 2026-08-11 工作日志

## 3D 记忆方块游戏 v2 — 严格参考 Machine Party 玩法

### v1（已废弃）
- 初版使用了 Human Benchmark 玩法（方块亮起→点击复原，3条命，可旋转视角）
- 用户反馈：需要严格参考 Machine Party Chisel Gauntlet 玩法

### v2（当前版本）
- 完全重写，严格参考 Machine Party Chisel Gauntlet：
  1. **一命制**：每关一次机会，失败即结束
  2. **两阶段流程**：先展示残缺立方体（目标形状）→ 再给完整立方体让玩家消除
  3. **固定视角**：角落视角 (5.2, 4.8, 5.2)，不旋转，参考 Machine Party
  4. **无间隙实体方块**：VOXEL_SIZE=0.998, SPACING=1.0，实体不透明
  5. **确定/重置按钮**：雕刻阶段可重置或提交答案
- UI 风格参考 Human Benchmark：深色背景、简洁面板、蓝色强调色
- 技术栈：Three.js 0.160.0 (ES Modules) + 原生 HTML/CSS/JS
- 游戏机制：
  - 目标缺失方块仅从 19 个可见面方块中选取（x=2 || y=2 || z=2）
  - 缺失数: min(level+1, 8)，记忆时间: max(2500, 5000-level*250)ms，雕刻时间: max(15000, 30000-level*1000)ms
  - 结果用颜色编码：绿色=正确保留，红色=错误消除，橙色=遗漏
  - 超时自动判失败
- 功能：平滑动画插值、Web Audio API 音效、localStorage 存档、响应式设计

### v2.1（优化）
1. **相机视角优化**：FOV 45→26，位置 (5.2,4.8,5.2)→(9.5,8,9.5)，长焦距减少透视收敛，竖线更接近垂直
2. **UI配色改为白色背景**：
   - `--bg: #ffffff`，面板 `rgba(248,249,252,0.92)`，文字 `#1a1a2e`
   - 方块配色调整：CARVE 0x6a7484（灰蓝）、TARGET 0x2d7dd2（蓝）、CORRECT 0x1ea672（绿）、WRONG 0xe0453b（红）、MISSED 0xf08c2e（橙）
   - 边线加深 0x3a4254，对比更清晰
   - 金色 #f0c040 → #d4a017（在白底上更可读）
   - 光照调整：AmbientLight 0xb0b4c0@0.55，KeyLight 0.9，FillLight 0x88aacc@0.2
3. **Bug修复 — 突然恢复初始关**：
   - `animate()` 中两个独立 `if` 改为 `if/else if`，防止同一帧同时执行 SHOWING 和 CARVING 逻辑
   - 添加 `trackedTimeout()` / `clearPendingTimeouts()` 追踪所有 setTimeout，startGame/startLevel/showGameOverScreen 时统一清理
   - `transitionToCarving()` 添加状态守卫 `if (gameState !== SHOWING) return`
   - `confirmCarving()` 添加 `resultProcessed` 标志防止重复执行
   - **根因（CSS穿透）**：`.btn-start` 和 `.btn` 的 `pointer-events:auto` 覆盖了 `.overlay-screen.hidden` 的 `pointer-events:none`，导致隐藏的开始/重启屏幕上的按钮仍可被点击。开始按钮居中，与立方体重叠，点击方块时误触按钮 → `startGame()` → level=1。修复：`.overlay-screen.hidden, .overlay-screen.hidden * { pointer-events: none !important; }`
4. **移除立方体 12 条边线**：删除 boundsHelper（BoxGeometry + EdgesGeometry + LineSegments）
5. **边线加粗 + 完整立方体改蓝色**：
   - 从 `LineSegments` + `LineBasicMaterial`（WebGL 不支持 linewidth）换成 `Line2` + `LineMaterial` + `LineSegmentsGeometry`，`linewidth=3` 像素
   - import map 新增 `three/addons/` 路径映射
   - 新增 `edgeMaterials[]` 数组追踪所有 LineMaterial，onResize 时更新 `resolution`
   - CARVE 状态颜色从灰色 `0x6a7484` 改为蓝色 `0x3a8fd0`
   - 所有状态边线颜色统一改为白色 `0xffffff`，提高对比度
6. **正交相机 + Hover 高亮**：
   - 透视相机换成 `OrthographicCamera`（`CAM_FRUSTUM=7`），彻底消除透视收敛，立方体边缘与屏幕完全平行
   - `onResize` 改为更新 left/right/top/bottom 而非 aspect
   - 新增 `HOVER` 外观状态：颜色变亮 `0x6ab8ec` + 轻微发光 + scale 1.06 + 边线全不透明
   - `updateHover()` 射线检测当前指针下方块，切换到 HOVER；`clearHover()` 恢复 CARVE
   - 桌面端 mousemove 触发 hover；移动端 pointerdown 立即触发预览，拖拽超过阈值后清除
   - `pointerleave` 事件：鼠标离开画布清除 hover
   - CSS 光标由 JS 控制：hover 方块时 `pointer`，否则 `default`
